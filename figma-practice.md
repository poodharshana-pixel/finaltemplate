# Figma Practical Quick Guide

1. Create a design file and a desktop frame (e.g. 1440 × 900).
2. Add a header, navigation, appointment form, service cards, and appointment list.
3. Use Auto Layout for form fields and cards; create consistent text and color styles.
4. Create a second frame for the successful booking state.
5. In Prototype mode, connect the Book Appointment button to the success frame using an On click interaction.
6. Click Present to demonstrate the prototype.
7. This is a design prototype only; it does not connect to MongoDB.
